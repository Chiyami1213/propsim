# PropSim component library

Machine-readable data for building and checking engines in PropSim: fluid and propellant properties (block A) and
the component catalog (block B) now; cycles, reference engines, materials, hybrid, electric and the graph/dashboard schemas in later blocks
(plan: brief blocks A to H).

**Rule:** no number without a source. Every value carries `quality` (`published`, `derived` or `estimated`),
`source_id` (a key of `sources.csv`) and `location` (page, table, figure or equation-of-state reference). A value no
source gives is left empty and listed in `gaps.md`; it is never filled with a guess. Disagreeing sources are both kept
and discussed in `conflicts.md`. `checks.md` is generated by `tools/check_library.py`.

Read the files with `propsim.data` (`fluids()`, `fluid_table()`, `sat_table()`, `scalar()`, `cea_species()`,
`components()`, `component_table()`, `validate()`); the test suite runs `validate()` and the published-value checks (`tests/data`).

## Conventions

- **SI units only.** Allowed unit strings: `1` (dimensionless), `K`, `Pa`, `Pa s`, `kg/m3`, `kg/mol`, `kg/s`,
  `J/mol`, `J/kg`, `J/(kg K)`, `W/(m K)`, `m/s`, `N/m`, `s`, `m`, `m2`, `m3`, `N`, `W`, `rad/s`, `kg m2`.
  Conversions from the source units are written in the `formula` column (e.g. `187 degF to K`).
- **Quality.** `published`: taken from the source (unit conversion only). `derived`: computed from published values
  or a published model; `formula` says how. `estimated`: engineering judgement; `formula` gives the reasoning.
- **Long format for scalars.** One value per row with its own provenance, so several sources of one property can sit
  side by side; `preferred = 1` marks the one the code uses (exactly one per fluid and property).
- **Generated tables** carry file-level provenance (all cells come from one model): see `fluids.csv`
  `table_source_id` and `table_location`. Rows of `cea_validation.csv` carry row-level provenance (one source per
  row).
- Specific speed is stored as the SI dimensionless value Omega_s = omega Q^0.5 / (g H)^0.75; the US-unit value of
  Huzel & Huang is Ns = 2733 Omega_s.
- Digitized curves are `published` with an `uncertainty` for the reading error.
- CSV: UTF-8, comma separated, header row, no merged cells, no comment lines. JSON: one schema per type in `schemas/`.

## Property backends

- `coolprop`: tables generated by `tools/build_fluid_tables.py` (CoolProp 8.0.0). The same EOS covers liquid and
  gas, so GOX, GN2 and GH2 use the LOX, LN2 and LH2 tables. RP-1 is represented by n-dodecane (`RP1_SURR`), a
  single-component surrogate (see `gaps.md`).
- `rocketprops`: storable propellants that CoolProp lacks (N2O4, MMH, UDMH, N2H4, H2O2 blends, RP-1). RocketProps
  is GPL-3.0, so like `rocketcea` it is an optional runtime dependency and none of its data is copied here.
- `none`: only the scalars in `fluid_scalars.csv` are available.

Regenerate: `python tools/build_fluid_tables.py [fluid_id ...]`, then `python tools/check_library.py`.
